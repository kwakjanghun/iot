Flow 실전 프롬프트 모음

2026년 9월 3일, 구글 Flow에서 실제로 실행한 클린봇 15초 광고 세션의 프롬프트 원문과, 다른 제품에 바로 쓰는 사례집입니다. 각 프롬프트의 복사 버튼을 누르고 Flow 채팅창에 붙여넣으면 됩니다.

규칙 세 가지. ① 실제 브랜드 이름·로고를 쓰지 않고 내가 지은 이름을 쓴다 ② 영상 안에 글자를 넣지 않는다(자막은 편집 앱에서) ③ 영상 생성 확인 창에서 "승인, 다시 묻지 않음"은 누르지 않는다.
프롬프트를 미리 다듬고 싶으면 제미나이(Gemini)에서. 수업에서 쓸 수 있는 AI는 제미나이입니다. 아래 첫 문장을 제미나이에 붙여넣고 "내 제품 ○○에 맞게 바꿔 줘"라고 하면 초안이 나옵니다. 그 결과를 Flow에 붙여넣습니다.

아홉 단계 한눈에

단계어디서무엇을
1Flow 홈+ 새 프로젝트 → 왼쪽 메뉴(모든 미디어·캐릭터·장면·도구), 오른쪽 에이전트 채팅창
2채팅창 아래 슬라이더 아이콘에이전트 설정 — 생성하기 전에 확인 항상, 동영상 비율 16:9(유튜브)/9:16(쇼츠), 모델 Omni 1.1 Flash, 저장
3채팅창첫 문장(아래 원문)을 붙여넣고 보내기 → 에이전트가 장면 5개를 짜 온다
4채팅창바로 승인하지 말고 3번 컷 수정 요청(아래 원문)
5채팅창"3x3 스토리보드 그리드 이미지를 먼저 하나 만들어줘" → 이미지 1장 값으로 5장면 확인
6채팅창장면 하나만 영상으로 요청 → "크레딧 12개를 사용하여 1개 동영상" 창 → 승인. "4개·5개"라고 나오면 거부. 에이전트가 "클립을 만들까요?"라고 물어도 "네"라고 하지 않는다
7왼쪽 캐릭터 → 신규 캐릭터제품 설명(아래 원문) → 만들기 → 연필로 이름 클린봇 → 캐릭터 정보 → 완료
8채팅창@ 입력 → 클린봇 선택 → 동작 하나만 쓴 문장(아래 원문)
9채팅창 또는 왼쪽 장면만든 클립을 Flow 안에서 3→4→5 순서로 이어 붙이기(아래 문장) → 위쪽 다운로드 → 제품명·카피는 유튜브 제목·설명에 → "변경되거나 합성된 콘텐츠" 켜기
크레딧이 한 번에 나가는 함정. 첫 문장에 "5컷"이 있어서 에이전트가 답 끝에 "각 장면을 3초 클립으로 만들어 볼까요?"라고 묻습니다. 여기에 "네"라고 하면 5개가 한꺼번에(60~75 크레딧) 만들어집니다. 반드시 아래처럼 답하세요.
에이전트가 "클립을 만들까요?"라고 물으면아니, 지금은 영상을 만들지 마. 먼저 3x3 스토리보드 그리드 이미지를 하나 만들고, 영상은 내가 컷 번호를 말할 때 한 번에 하나씩만 만들어줘.
저예산 코스 (크레딧 30 안팎). 스토리보드 1장 + 3번 컷(12) + 4번 컷(@캐릭터, 15) = 27. 두 클립만으로도 편집에서 8초 + 7초 = 15초가 됩니다. 나머지 컷은 스토리보드 이미지를 잘라 정지 컷으로 씁니다.

실제 세션 프롬프트 — 클린봇 (로봇청소기)

아래 문장은 전부 실제로 입력한 것이고, 그 아래 "에이전트 답"은 실제로 돌아온 내용을 요약한 것입니다.

3

첫 문장 — 한 번에 다 넣는다

채팅창에 붙여넣기15초 로봇청소기 광고를 만들고 싶어. 제품 이름은 클린봇(가상 브랜드). 강조할 기능은 딱 하나, 외출 중에 스마트폰 앱으로 청소를 시작하는 기능. 보는 사람은 혼자 사는 20대. 밤의 도시 아파트, 차분하고 세련된 분위기, 실사 광고 느낌. 3초씩 5컷으로 장면을 제안해줘. 순서는 훅, 문제, 기능 작동, 증거, 제품명. 실제 브랜드 로고는 쓰지 말고, 영상 안에 글자는 넣지 마.

에이전트 답(실제): 장면 1 훅 — 야경이 보이는 고층 아파트 거실, 팬 샷 · 장면 2 문제 — 밤거리에서 폰을 보는 20대 남성 · 장면 3 기능 작동 — 앱 '청소 시작' 버튼을 누르는 손가락 클로즈업 · 장면 4 증거 — LED 링이 켜진 로봇이 바닥을 미끄러진다 · 장면 5 제품명 — 가구 옆에 멈춘 클린봇. 그리고 "15초를 한 번에 만들기는 어려우니 3초 클립 5개로 각각 만들자"고 제안.

4

3번 컷 수정 요청 — 기능이 눈에 보이게

채팅창에 붙여넣기3번 장면을 고쳐줘. 손가락 클로즈업만 있으면 밖에서 눌렀다는 게 안 보여. 밤거리에서 남성이 든 스마트폰 화면(청소 시작 버튼)과, 그 뒤 멀리 보이는 아파트 창문에 클린봇의 파란 LED 링이 켜지는 모습이 한 화면에 같이 보이게 바꿔줘. 나머지 장면은 그대로.

에이전트 답(실제): 장면 3 수정본 — 전경에 폰 화면, 배경 멀리 아파트 창문에서 파란 LED가 켜진다. 카메라는 딥 포커스, 폰에서 창문으로 초점 이동.

5

스토리보드 먼저

채팅창에 붙여넣기3x3 스토리보드 그리드 이미지를 먼저 하나 만들어줘. 영상 안에 글자는 넣지 마.

결과: 이미지 1장에 5장면(야경 거실 / 밤거리 남성 / 폰+창문 LED / 바닥의 로봇 / 의자 옆 로봇). 이미지를 누르면 편집 화면(모델 Nano Banana 2)이 열리고, 오른쪽에 Flow가 내부적으로 쓴 영어 프롬프트가 보입니다. 우리가 쓴 여섯 칸이 그대로 번역되어 있고, 마지막에 NO TEXT, NO LOGOS, and NO CAPTIONS가 들어 있습니다. 그래서 첫 문장에 "글자 금지·로고 금지"를 꼭 넣습니다.

6

영상 클립 요청 → 크레딧 확인 창

채팅창에 붙여넣기스토리보드의 3번 장면(폰 화면과 창문 LED)을 영상 클립으로 만들어줘. 앱의 시작 버튼을 누르는 순간 멀리 창문에 파란 빛이 켜지는 동작 하나만. 영상 안에 글자는 넣지 마.

보내면 채팅 안에 "크레딧 12개를 사용하여 1개 동영상 생성을 시작할까요?" 카드가 뜹니다. 선택지는 승인 / 승인, 다시 묻지 않음 / 거부. 승인만 누릅니다. 클립 5개를 다 만들면 60크레딧이므로 한 클립씩 확인하고, 마음에 안 들면 이미지 단계로 돌아가서 고칩니다.

7

제품을 캐릭터로 등록

왼쪽 캐릭터 → 신규 캐릭터. 화면의 "와일드 카드: 인간 외에도 무엇이든 캐릭터가 될 수 있습니다"가 근거입니다.

"캐릭터를 설명해 주세요" 칸에 붙여넣기흰색 원형 로봇청소기. 윗면 가운데에 파란 LED 링, 무광 매트 재질, 범퍼는 진회색. 로고나 글자 없음. 이름은 클린봇.

만들기 → 이미지가 나오면 제목 옆 연필로 이름을 클린봇으로 바꾸고, 아래 "캐릭터 정보(선택사항)"에 움직임을 적습니다.

캐릭터 정보 칸에 붙여넣기집 안 바닥을 미끄러지듯 조용히 움직인다. 작동할 때 윗면 파란 LED 링이 켜진다. 스마트폰 앱으로 밖에서 청소를 시작할 수 있다.

오른쪽 위 완료.

8

@클린봇으로 부르기 — 동작 하나만

채팅창에 @를 치면 미디어 목록이 뜹니다. 캐릭터 클린봇을 고르면 입력칸에 칩이 붙습니다. 그 뒤에 이어서 씁니다.

@클린봇 선택 후 이어서 입력이 어두운 거실 바닥을 왼쪽에서 오른쪽으로 미끄러지듯 지나간다. 바닥 높이 고정 카메라, 창밖 도시 야경, 파란 LED 링만 빛난다. 이 동작 하나만, 글자 없이.
뒤 클립을 앞 클립과 이을 때 꼭 붙이는 문장앞 영상의 마지막 화면에서 그대로 이어지는 8초 영상. 앞 영상과 같은 장소, 같은 시간대, 같은 색감을 유지해줘.
9

Flow 안에서 이어 붙이기 (편집 앱 없이)

채팅창에 붙여넣기 — 만든 컷 번호만 남기기지금까지 만든 클립을 3번, 4번, 5번 순서로 이어서 하나의 영상(장면)으로 만들어줘. 새 영상은 생성하지 말고, 있는 클립만 이어 붙여줘. 각 클립은 앞뒤를 조금 잘라 3~4초씩만 써서 전체 15초 안에 맞춰줘.

확인 창에 크레딧이 뜨면 거부한다(이어 붙이기는 새 생성이 아니다). 채팅으로 안 되면 왼쪽 장면 메뉴에서 클립을 열고 타임라인 끝의 +로 다음 클립을 추가한다. 제품 이름과 카피는 영상 안이 아니라 유튜브 제목·설명에 쓴다.

실전 사례집 — 첫 문장만 바꾼다

수업 후 보강. 첫 수업 결과가 밋밋해서, 사례집 문장에는 컷마다 움직임 하나 + 사물인터넷 3요소(앱 화면 · 제품 반응 · 연결 장면) 조건을 넣었습니다. 클린봇 실제 세션 원문(위)에는 이 조건이 없었고, 그래서 결과가 조용했습니다.

구조는 클린봇과 같습니다. 제품 이름 · 기능 하나 · 보는 사람 · 분위기 네 곳만 바뀝니다. 나머지 단계(수정 요청, 스토리보드, 캐릭터, @)는 이름만 바꿔 그대로 씁니다.

① 스마트 조명 — 루미어

첫 문장15초 스마트 조명 광고를 만들고 싶어. 제품 이름은 루미어(가상 브랜드). 강조할 기능은 딱 하나, 귀가 전에 앱으로 집 조명을 미리 켜는 기능. 보는 사람은 야근이 잦은 직장인. 밤의 현관과 거실, 따뜻한 빛, 실사 광고 느낌. 3초씩 5컷으로 장면을 제안해줘. 순서는 훅, 문제, 기능 작동, 증거, 제품명. 컷마다 눈에 보이는 움직임을 하나씩 넣고(카메라가 밀고 들어가거나 옆으로 따라가기), 정지 화면처럼 보이는 컷은 없게 해줘. 사물인터넷이 보이게: 스마트폰 앱 화면(버튼·알림), 제품이 반응하는 모습(불빛·소리·움직임), 그리고 폰과 제품이 연결됐다는 게 한 화면에서 보이는 장면을 꼭 넣어줘. 실제 브랜드 로고는 쓰지 말고, 영상 안에 글자는 넣지 마. 지금은 장면 계획만 세우고 영상은 아직 만들지 마.
캐릭터 설명둥근 유리 갓의 스마트 전구형 조명. 켜지면 따뜻한 주황빛, 꺼지면 무광 흰색. 로고나 글자 없음. 이름은 루미어.

자주 실패하는 점. 공기청정기는 움직이지 않아서 영상이 정지 화면처럼 심심하게 나옵니다. 동작 칸에 눈에 보이는 움직임을 하나 넣습니다.
