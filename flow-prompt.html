Flow 따라하기 프롬프트 생성기

아래 내 제품 칸을 채우면, 각 단계의 실제 Flow 화면 아래에 그 화면에서 붙여넣을 문장이 내 제품으로 완성되어 나옵니다. 화면은 2026년 9월 3일 실제 세션(클린봇)을 그대로 캡처한 것입니다. 쓴 내용은 이 브라우저에 자동 저장됩니다.

내 제품

제품을 캐릭터로 (7단계에 씀)

지금 제품: —입력으로 ↑

1새 프로젝트

Flow 홈 가운데 + 새 프로젝트 → 왼쪽 메뉴, 오른쪽 에이전트 채팅창

2에이전트 설정 — 확인은 '항상', 비율은 목적대로

채팅창 아래 슬라이더 아이콘 → 에이전트 설정 → 저장

3첫 문장 — 한 번에 다 넣는다

채팅창에 아래 문장을 붙여넣고 보내기 → 에이전트가 장면 5개를 짜 온다

채팅창에 붙여넣기

4바로 승인하지 않는다 — 3번 컷 고치기

기능이 작동하는 컷(3번)이 눈에 보이게 한 번 고친다

채팅창에 붙여넣기

5스토리보드 먼저 — 이미지 한 장 값

채팅창에 붙여넣기
스토리보드 한 칸만 고칠 때

6영상 생성 — 크레딧 확인 창에서 '승인'만

채팅창에 붙여넣기 (3번 컷 클립)
크레딧. 클립 1개 = 12 (캐릭터 포함 15). 5개면 60~75. 한 클립씩 승인하고, 마음에 안 들면 이미지 단계로 돌아가서 고친다.

7제품을 캐릭터로 등록한다

왼쪽 캐릭터 → 신규 캐릭터

"캐릭터를 설명해 주세요" 칸에 붙여넣기 → 만들기
"캐릭터 정보(선택사항)" 칸에 붙여넣기 → 완료

8@로 부르기 — 어느 클립에서든 같은 제품

채팅창에 @ 입력 → 목록에서 내 캐릭터 선택 → 이어서 문장

@캐릭터 선택 후 이어서 입력
뒤 클립을 앞 클립과 이을 때 꼭 붙이는 문장

9다운로드 → 편집 앱에서 자막 → 업로드 표시

편집 팁 (속도감). 3초 × 5컷보다 1~2초 × 9컷이 광고답다. 같은 클립을 두 구간으로 나눠 쓰고, 컷마다 살짝 밀고 들어가는 줌, 자막은 두세 단어로 크게.

결과가 이상할 때 — 한 칸만 고친다
