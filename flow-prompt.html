Flow 완성형 광고 생성기

한 번 생성(12~15 크레딧)으로 10초 광고 한 편이 완성되게 만듭니다. 컷을 여러 개 만들어 이어 붙이지 않고, 한 컷(끊김 없는 카메라 움직임) 안에 문제 → 앱 버튼 → 제품 반응 → 제품 클로즈업이 다 들어가게 프롬프트를 짭니다. 아래 칸을 채우면 각 단계의 실제 Flow 화면 아래에 붙여넣을 문장이 내 제품으로 완성됩니다.

내 제품

10초 안에 들어갈 네 장면 — 실제 광고(LG STEM 30초)와 같은 문법: 인물 한마디 → 기능 → 히어로

이 칸들이 곧 광고의 뼈대입니다. ① 인물이 카메라를 보고 한마디(대사가 함께 생성된다) → ② 폰 버튼 → ③ 제품 반응을 가까이서(연결이 보이게) → ④ 제품 히어로 샷 + 폰 완료. 실제 광고가 "인물 인터뷰 → 기능 클로즈업 → 제품 히어로"로 가는 것과 같은 순서입니다.

제품을 캐릭터로 (3단계에 씀)

지금 제품: —입력으로 ↑

1새 프로젝트

Flow 홈 가운데 + 새 프로젝트 → 왼쪽 메뉴, 오른쪽 에이전트 채팅창

2에이전트 설정 — 확인은 '항상', 개수는 x1

채팅창 아래 슬라이더 아이콘 → 에이전트 설정 → 저장

3제품을 캐릭터로 등록한다 (영상 만들기 전에)

왼쪽 캐릭터 → 신규 캐릭터. 이미지 1장 값. 이걸 먼저 해야 영상 속 제품이 내가 정한 모양으로 나온다.

"캐릭터를 설명해 주세요" 칸에 붙여넣기 → 만들기
"캐릭터 정보(선택사항)" 칸에 붙여넣기 → 완료

4첫 문장 — 10초 한 컷 완성 광고 계획

채팅창에 붙여넣고 보내기. 계획만 받는다(영상은 아직). 순서는 실제 가전 광고(LG STEM 30초)에서 가져왔다: 인물이 카메라를 보고 한마디 → 기능 클로즈업 → 제품 히어로. 광고의 자막 자리는 Flow에서 글자를 못 넣으니 인물의 대사로 대신한다.

① 한마디 0–2② 버튼 2–4③ 제품 반응 4–8④ 히어로 8–10
채팅창에 붙여넣기

5계획 고치기 — 연결이 한 화면에 보이는가

계획에서 "폰 버튼 누르는 순간"과 "제품이 반응하는 모습"이 따로 떨어져 있으면 고친다. 이게 사물인터넷 광고의 핵심 장면.

채팅창에 붙여넣기

6(선택) 스토리보드 한 장으로 미리 보기

이미지 1장 값. 영상(12~15)보다 싸니, 크레딧이 애매하면 이걸로 먼저 확인하고 영상은 한 번만.

채팅창에 붙여넣기

7완성 영상 생성 — 한 번, 1개

채팅창에 @ → 내 캐릭터 선택 → 아래 문장. 확인 창에 "1개 동영상"일 때만 승인.

@캐릭터 선택 후 이어서 입력
이 한 번으로 끝. 10초짜리 완성 광고 한 편이 나온다(1~3분 대기). 소리도 함께 생성된다. 이어 붙이기·편집 없음.

8결과가 아쉬우면 — 한 칸만 고쳐서 다시 (선택)

한 번에 두 가지를 바꾸지 않는다. 바꾼 칸이 하나여야 무엇 때문에 좋아졌는지 안다. 재생성도 12~15 크레딧.
