# 빌드 도구

새 챕터 대본을 만든 뒤 **`전체_빌드.bat`을 더블클릭**하면 끝입니다.
메뉴·영상·웹사이트가 한 번에 갱신되고, 물어보면 GitHub에도 올라갑니다.

## 이름 규칙 — 이것만 지키면 자동으로 걸립니다

앞 **두 자리 숫자**로 짝을 찾습니다.

| 넣을 것 | 위치와 이름 |
|---|---|
| 소스 실행기 | `ESP32 올인원 키트_교안\05장_소리_소스실행기.html` (01장은 `_조립순서기.html`) |
| 수업 대본 | `ESP32 올인원 키트_교안\05장_소리_수업진행대본.html` |
| 해설 영상 | `사물영상\05_00_소리_통합_코드해설.mp4` |
| 실습 영상 | `ESP32 올인원 키트_교안\05 소리\실습영상\*.mp4` |
| 교재 PDF | `ESP32 올인원 키트_교안\05 소리\*.pdf` |
| 실습 코드 | `ESP32 올인원 키트_교안\05 소리\실습코드\` |

대본 파일명이 `NN장_...._수업진행대본.html` 형식이 아니면 인식되지 않습니다.

## 스크립트 세 개가 하는 일

### `build_index.py`
구글드라이브 키트 폴더에 **`index.html`(수업 홈)** 을 만듭니다.
챕터 폴더를 훑어 카드를 자동 생성 — 대본이 있으면 초록, 없으면 "준비 중".

### `add_video.py`
대본 HTML 맨 위에 **영상 섹션**과 **← 수업 홈** 링크를 넣습니다.
이미 들어 있으면 건너뛰므로 여러 번 돌려도 안전합니다.

### `build_web.py`
드라이브 자료 → **GitHub Pages용 웹 빌드**를 이 저장소에 만듭니다.
로컬본과 다른 점:

- 파일명을 ASCII로 — 한글 URL 문제 회피. 장 번호가 앞이라 순서는 그대로
  - `ch05-buzzer.html` 소스 실행기 (번호→영문 이름은 `build_web.py`의 `SLUG` 표)
  - `ch03-script.html` 수업 대본 · `ch04-easy.html` 아주 쉬운 설명서
  - `pinmap-3d.html` ESP32 핀맵 3D 뷰어 (올인원_사물 최상위 폴더에서 가져옴)
- `<video>`를 **안내 문구로 교체** (영상은 용량 때문에 안 올림)
- 교재 PDF·실습코드·라이브러리는 **넣지 않음** (ICBANQ 저작물)

## 두 벌로 나뉘는 이유

| | 구글 드라이브 | 웹사이트 |
|---|---|---|
| 영상 | 바로 재생 | 안내 문구 |
| 교재·실습코드 | 있음 | 없음 |
| 용도 | 수업 진행 | 학생 예습·복습 |

- 저장소를 **구글 드라이브 안에 두지 마세요.** 동기화 중 `.git`이 깨질 수 있습니다.
